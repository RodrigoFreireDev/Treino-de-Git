# 🏆 Checklist de Conquistas (Badges) do GitHub

Este guia prático em Markdown traz o passo a passo completo para desbloquear todas as conquistas do GitHub, ordenado por nível de dificuldade.

---

## 🟢 Nível Fácil (Execute sozinho em 5 minutos)

### [ ] ⚡ **Quickdraw**
- [ ] Acesse um repositório próprio (ou crie um novo repositório de teste).
- [ ] Vá na aba **Issues** ou **Pull requests**.
- [ ] Crie uma nova Issue ou Pull Request.
- [ ] Feche a Issue ou PR em **menos de 5 minutos** após a criação.

---

### [ ] 🦡 **YOLO**
- [ ] No seu repositório, crie uma nova *branch* (ex: `teste-yolo`).
- [ ] Faça uma alteração simples no código ou no `README.md` e dê commit nessa *branch*.
- [ ] Abra um **Pull Request** para a *branch* principal (`main`).
- [ ] Clique diretamente em **Merge pull request** e **Confirm merge** sem solicitar nem receber revisões de código.

---

### [ ] 🦈 **Pull Shark**
- [ ] **Nível Bronze (2 PRs):**
  - [ ] Abra e mescle o 1º Pull Request no seu próprio repositório.
  - [ ] Abra e mescle o 2º Pull Request.
- [ ] **Nível Prata (16 PRs):**
  - [ ] Realize o processo de abrir e mesclar PRs 16 vezes no total.
- [ ] **Nível Ouro (128 PRs):**
  - [ ] Chegue ao total de 128 PRs mesclados.
- [ ] **Nível Platina (1.024 PRs):**
  - [ ] Chegue ao total de 1.024 PRs mesclados.

---

## 🟡 Nível Médio (Exige colaboração simples ou apoio)

### [ ] 👯 **Pair Extraordinaire**
- [ ] Escolha um colega para colaborar em um projeto ou utilize duas contas de teste.
- [ ] No terminal, ao realizar o commit no Git, insira a tag de coautoria no final da mensagem do commit:
  ```text
  git commit -m "Adiciona nova funcionalidade
  
  Co-authored-by: NOME_DO_COLEGA <EMAIL_DO_COLEGA@exemplo.com>"
  ```
  *(Atenção: Deixe uma linha em branco entre o título da mensagem e a tag `Co-authored-by`).*
- [ ] Suba a alteração para uma *branch* e abra um **Pull Request**.
- [ ] Realize o **Merge** desse Pull Request para a *branch* principal.

---

### [ ] 💖 **Public Sponsor**
- [ ] Acesse o perfil do desenvolvedor ou projeto que deseja apoiar no [GitHub Sponsors](https://github.com/sponsors).
- [ ] Clique em **Sponsor**.
- [ ] Selecione um plano de apoio (muitos projetos oferecem planos a partir de **$1 USD**).
- [ ] Conclua o pagamento e garanta que a opção de exibição do patrocínio no seu perfil esteja pública.

---

## 🔴 Nível Difícil (Exige comunidade e engajamento)

### [ ] ⭐ **Starstruck**
- [ ] Crie um projeto útil, biblioteca open-source, template ou lista qualificada (`awesome-list`).
- [ ] Divulgue seu repositório na comunidade (Reddit, Dev.to, LinkedIn, Twitter/X, Discord).
- [ ] **Nível Bronze:** Alcance **16 estrelas** no mesmo repositório.
- [ ] **Nível Prata:** Alcance **128 estrelas**.
- [ ] **Nível Ouro:** Alcance **512 estrelas**.
- [ ] **Nível Platina:** Alcance **4.096 estrelas**.

---

### [ ] 🧠 **Galaxy Brain**
- [ ] Encontre repositórios ativos que possuam a aba **Discussions** habilitada.
- [ ] Procure por perguntas ou dúvidas de outros usuários.
- [ ] Responda de forma clara e assertiva com a solução do problema.
- [ ] Faça com que o autor da discussão ou o mantenedor do repositório marque sua resposta como **"Answered" (Solução)**.
- [ ] **Nível Bronze:** **2 respostas aceitas**.
- [ ] **Nível Prata:** **8 respostas aceitas**.
- [ ] **Nível Ouro:** **16 respostas aceitas**.
- [ ] **Nível Platina:** **32 respostas aceitas**.
